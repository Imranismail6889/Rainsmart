# RainSmart – Rainwater Harvesting Calculator

## About the Project

RainSmart is a simple, responsive web application that estimates how much rainwater can be collected from a rooftop based on its area and local rainfall.

The project aims to help users understand the potential benefits of rainwater harvesting and encourage the efficient use of rainwater.

## Features

- Calculate estimated rainwater collection.
- Enter rooftop area and rainfall amount.
- Apply an estimated collection efficiency of 80%.
- Display the calculated result and related statistics.
- Responsive design for desktop and mobile devices.
- Simple and user-friendly interface.

## Technologies Used

- **HTML5** – Structure of the website.
- **CSS3** – Styling, layout, and responsive design.
- **JavaScript** – Calculation logic and interactive elements.

## How It Works

RainSmart estimates the amount of collectable rainwater using the following formula:

**Estimated Rainwater (litres) = Roof Area (m²) × Rainfall (mm) × 0.8**

The factor 0.8 represents an assumed collection efficiency of 80%. Actual collection may vary depending on the roofing material, drainage system, and water losses.

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` in a web browser.

No additional installation is required.
